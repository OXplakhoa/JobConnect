# Mission: Nắm vững JobConnect để demo cho cô giáo

## Why
Bạn cần thuyết trình đồ án JobConnect trước cô giáo và chứng minh mình hiểu rõ code — không chỉ là người copy-paste. Cô có thể hỏi bất kỳ chức năng nào, yêu cầu giải thích flow, hoặc yêu cầu sửa trực tiếp (màu sắc, text) trong buổi demo.

## Success looks like
- Giải thích được Clean Architecture 3 tầng bằng lời, không cần nhìn code
- Trace được bất kỳ chức năng nào từ UI → Provider → UseCase → Repository → Datasource → Supabase
- Giải thích AI Suggestion hoạt động thế nào (Gemini embedding, cosine similarity, Match Score)
- Biết file nào cần mở để sửa màu, sửa text ngay trong buổi demo
- Trả lời câu hỏi "Tại sao dùng Riverpod/Repository pattern/Either?" mà không lúng túng

## Constraints
- Demo sắp tới (thời gian ngắn)
- Cần học qua code thực của project, không phải lý thuyết chung

## Out of scope
- Thêm feature mới trước demo
- Học Flutter/Dart từ đầu (đã biết cơ bản)
- Deep dive vào Supabase Edge Function TypeScript code
