Riverpod State & Navigation

Tại sao app tự redirect đúng sau login — và cách Riverpod quản lý state

Auth State — 4 trạng thái

AuthInitial AuthUnauthenticated AuthAuthenticated AuthError

AuthInitial — app vừa mở, đang check session (splash screen)

AuthUnauthenticated — chưa đăng nhập → redirect /login

AuthAuthenticated — đã đăng nhập. Chứa: userId, role, isOnboardingComplete, isBanned

AuthError — lỗi load profile → force logout

Auth Provider — keepAlive + Supabase stream

@Riverpod(keepAlive: true)  // không tự dispose khi không ai watch
class Auth extends _$Auth {
  @override
  AuthState build() {
    // Lắng nghe Supabase auth stream
    _subscription = Supabase.instance.client.auth
        .onAuthStateChange.listen((data) {
      if (data.session == null) {
        state = const AuthUnauthenticated();
      } else {
        _fetchProfile(data.session!.user.id);
      }
    });
    // ...
  }
}
Tại sao keepAlive? Auth là global state — cần tồn tại suốt vòng đời app. Nếu không keepAlive, Riverpod dispose khi không có widget nào watch → mất session.

Router redirect — tự động đi đúng chỗ

go_router có redirect callback, chạy mỗi khi auth state thay đổi:

redirect: (context, state) {
  final auth = ref.read(authProvider);

  // Chưa đăng nhập → vào login
  if (auth is AuthUnauthenticated) return '/login';

  if (auth is AuthAuthenticated) {
    if (auth.isBanned)               return '/banned';
    if (!auth.isOnboardingComplete)  return '/onboarding';

    // Đã login, đang ở trang public → vào home đúng role
    if (publicRoutes.contains(currentPath)) {
      return switch (auth.role) {
        UserRole.recruiter => '/recruiter/home',
        UserRole.admin     => '/admin/dashboard',
        _                  => '/',           // seeker
      };
    }
  }
  return null; // không redirect
}
Dart 3 switch expression — không cần case/break. _ là wildcard (default). Cô có thể hỏi về syntax này.

ref.watch() vs ref.read()

ref.watch() — trong build() của widget/provider. Reactive: rebuild tự động khi provider thay đổi.

ref.read() — trong event handler (onPressed). One-time: đọc giá trị tại thời điểm đó, không subscribe.

// ✅ Trong provider — watch để auto-rebuild khi auth đổi
@riverpod
Future<List<AiSuggestion>> aiSuggestions(Ref ref) async {
  final auth = ref.watch(authProvider);  // watch
  if (auth is! AuthAuthenticated) return [];
  ...
}

// ✅ Trong event handler — read vì chỉ cần giá trị hiện tại
onPressed: () async {
  final notifier = ref.read(aiEmbeddingNotifierProvider.notifier);
  await notifier.rebuildSuggestions();
}

3 Shell — bottom nav không bị re-render

App có 3 shell riêng: SeekerShell / RecruiterShell / AdminShell.

Dùng StatefulShellRoute.indexedStack — mỗi tab có navigator stack riêng. Chuyển tab không rebuild các tab khác, không mất state.

Root-level routes (/job/:id, /chat/:id, /application/:id) nằm ngoài shell để tránh crash duplicate GlobalKey khi navigate từ Notification.
