Luồng tạo AI Suggestion

Bước 1 — Tạo Profile Embedding

Khi Seeker update Profile hoặc Skills:

// Provider gọi AiEmbeddingNotifier
await ref.read(aiEmbeddingNotifierProvider.notifier)
         .rebuildProfileEmbedding();

// → AiSuggestionDatasource.rebuildProfileEmbedding()
// → Supabase Edge Function "ai" (action: rebuild_profile_embedding)
// → Gemini API tạo vector 768 chiều từ profile text
// → Lưu vào bảng profile_embeddings

Bước 3 — Tính Match Score & Cache 
// Edge Function tính:
SELECT job_id,
       1 - (job_embedding <=> profile_embedding) AS match_score
FROM job_embeddings, profile_embeddings
WHERE profile_id = current_user
ORDER BY match_score DESC
LIMIT 20;

// Lưu kết quả vào ai_suggestions với TTL = 24h

Skill Gap — tính realtime khi xem Job Detail

Skill Gap = danh sách Required Skills của Job Post mà Seeker chưa có trong User Skills.

Tính realtime khi mở JobDetailPage — không lưu vào DB. So sánh 2 danh sách:

skillGap = job.requiredSkills
             .where((s) => !seeker.userSkills.contains(s))
             .toList();

Hiển thị badge "Thiếu X kỹ năng" để Seeker biết cần học thêm gì.

Tại sao dùng Edge Function thay vì gọi Gemini từ app?

3 lý do:
1. Bảo mật API key — Gemini key không bao giờ nằm trong app (dễ bị decompile). Edge Function chạy server-side.
2. Heavy computation — tính cosine similarity trên 768 chiều × N jobs nên làm server-side.
3. pgvector — PostgreSQL extension <=> là cosine distance built-in, cực nhanh.
