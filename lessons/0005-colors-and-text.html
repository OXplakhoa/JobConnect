Cách đổi màu chính (accent) — ví dụ sang xanh dương

// lib/core/theme/app_colors.dart — dòng ~14
static const Color accent = Color(0xFF2563EB);  // ← đổi hex này
//                                   ^^^^^^^^
//                                   F97316 = cam (hiện tại)
//                                   2563EB = xanh dương
//                                   059669 = xanh lá
//                                   7C3AED = tím

Lưu file → Flutter hot reload (r trong terminal hoặc Ctrl+S nếu dùng IDE) → toàn bộ app đổi màu ngay.

Sửa text — 2 cách

Cách 1 — AppStrings (strings hệ thống)

Strings dùng lại nhiều nơi (tab label, button text chung) nằm trong:

lib/core/constants/app_strings.dart
class AppStrings {
  static const home = 'Trang chủ';
  static const search = 'Tìm kiếm';
  static const conversations = 'Tin nhắn';
  // ...
}
Cách 2 — Inline string trong file màn hình

Text cụ thể của từng screen — tìm bằng VS Code search (Cmd+Shift+F):

// Ví dụ: tìm "Ứng tuyển" để sửa nút Apply
// → mở lib/features/application/presentation/pages/apply_page.dart
// → tìm dòng Text('Ứng tuyển') rồi sửa
Mẹo demo: Cmd+Shift+F → gõ text cần sửa → double-click kết quả → sửa → hot reload.

Hot reload vs Hot restart

Hot reload (r) — inject code mới, giữ state. Dùng để xem thay đổi UI ngay lập tức.

Hot restart (R / Shift+R) — restart app từ đầu, reset state. Dùng khi thay đổi không hot-reload được (provider, route...).

Mẹo demo: Sửa màu/text → nhấn r trong terminal → cô thấy thay đổi ngay. Không cần rebuild toàn bộ.
